---

# مفاهیم اصلی

## Loss Function

* معیار اندازه‌گیری خطای مدل
* هدف آموزش: کمینه کردن Loss

---

## Gradient

* مشتق Loss نسبت به وزن‌ها
* مشخص می‌کند هر وزن چقدر باید تغییر کند.

---

## Backpropagation

* محاسبه Gradient برای تمام لایه‌ها
* استفاده از Chain Rule
* انتقال خطا از خروجی به لایه‌های ابتدایی

---

## Update Rule

[
W_{new}=W_{old}-\eta\nabla L
]

---

## Learning Rate

* اندازه قدم اصلاح وزن‌ها

کم:

* آموزش کند

زیاد:

* نوسان
* عدم همگرایی

---

## Batch

تعداد نمونه‌هایی که هم‌زمان وارد مدل می‌شوند.

---

## Mini Batch

روش رایج آموزش

مزایا:

* حافظه کمتر
* سرعت بیشتر
* پایداری بیشتر

---

## Epoch

یک بار مشاهده کامل کل دیتاست.

---

# Gradient Descent

هدف:

حرکت در خلاف جهت Gradient برای کاهش Loss

---

# SGD

* محاسبه Gradient روی Mini Batch
* سریع‌تر از Gradient Descent کلاسیک
* دارای نویز بیشتر

---

# Momentum

از جهت حرکت قبلی نیز استفاده می‌کند.

مزایا:

* کاهش نوسان
* همگرایی سریع‌تر

---

# Adam / AdamW

ترکیب:

* Momentum
* Adaptive Learning Rate

مزایا:

* سریع
* پایدار
* انتخاب پیش‌فرض اکثر LLMها و VLMها

---

# Vanishing Gradient

علت:

کوچک شدن تدریجی Gradient در شبکه‌های عمیق

نتیجه:

* توقف یادگیری لایه‌های ابتدایی

---

# Transfer Learning

استفاده از مدل از قبل آموزش‌دیده و آموزش مجدد روی مسئله جدید.

---

# Full Fine-tuning

* تمام وزن‌ها آموزش می‌بینند.
* حافظه و زمان بسیار زیاد

---

# PEFT

Parameter Efficient Fine-Tuning

هدف:

آموزش تعداد کمی از پارامترها

---

# Adapter

* شبکه کوچک بین لایه‌ها
* فقط Adapter آموزش می‌بیند.

---

# LoRA

Low Rank Adaptation

ایده:

[
W'=W+\Delta W
]

که:

[
\Delta W=A\times B
]

* وزن اصلی تغییر نمی‌کند.
* فقط ماتریس‌های کوچک A و B آموزش می‌بینند.

---

# نکات مهم

* Base Model همیشه ثابت می‌ماند.
* LoRA فقط یک اصلاح روی رفتار مدل اعمال می‌کند.
* هنگام Inference:

  * Base Model استفاده می‌شود.
  * LoRA نیز هم‌زمان اعمال می‌شود.
* برای تغییر وظیفه فقط فایل LoRA عوض می‌شود.
* نیازی به دانلود مجدد مدل اصلی نیست.
