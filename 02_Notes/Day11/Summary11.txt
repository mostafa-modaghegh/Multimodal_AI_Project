# خلاصه روز یازدهم

* ساختار داخلی SmolVLM بررسی شد.
* محل نصب LoRA روی q/k/v/o مشخص شد.
* تعداد پارامترهای قابل آموزش به حدود ۱٪ کاهش یافت.
* خروجی Processor و Tensorهای ورودی مدل تحلیل شدند.
* مفهوم Image Token و تفاوت آن با تصویر واقعی درک شد.
* Prompt واقعی مدل Decode و بررسی شد.
* نحوه ساخت Labels و دلیل استفاده از مقدار `-100` برای Padding و Image Tokenها بررسی شد.
* منطق Data Collator تا قبل از مرحله Trainer به طور کامل فهمیده شد.
