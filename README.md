# Multimodal AI Project

This repository contains materials and practical work developed as part of a university project on **Multimodal Artificial Intelligence**.

## Contents

- **Papers:** Research papers related to multimodal AI.
- **Notes:** Study notes and technical explanations.
- **Slides:** Presentation materials.
- **Demo:** Demonstrations of multimodal AI concepts.
- **Code:** Code developed during the project.
- **Images:** Images and visual resources.
- **References:** Additional learning resources and references.
- **Datasets:** Dataset-related resources used for the project.

## Objective

The objective of this project is to explore multimodal AI concepts and gain practical experience with models and techniques that work with different types of data, such as images and text.

## Purpose

This repository serves as a record of my university project, including research materials, notes, code, and practical experiments related to multimodal AI.
